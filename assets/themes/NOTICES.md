# Theme credits and licenses

8bitPad's Qt/Scintilla theme adapter is independently implemented and licensed
under GPL-3.0-or-later, like 8bitPad. The color-role mappings in `catalog.json`
are adaptations for this application: comment contrast, some light-theme colors,
UI surfaces, selection colors, and semantic assignments can differ from upstream.
No implementation code from 8bitShell/8bitShell is included.

The following upstream palettes and theme projects informed those mappings.
Their original, unmodified license notices are included in `licenses/` and in
the application's Qt resources under `:/themes/licenses/`. Retrieved 2026-10-23.
Every upstream project listed below uses the MIT license.

Classic Light is an original neutral white palette licensed under GPL-3.0-or-later.

Silverhand, V and K are original 8bitPrograms editor palettes inspired by the
yellow, red and cyan colors of Cyberpunk 2077. They use no game artwork or fonts.

Blueberi and Raspberi are 8bitPad's independently mapped versions of the user's
existing custom palette preferences; these new mappings are GPL-3.0-or-later.
Theme names identify palette compatibility and do not imply endorsement by the
upstream authors. No paid Dracula PRO, Vira, or Material Theme product is bundled.
